Campus Companion

AI-Powered Local Study Assistant

1. Project Overview

Campus Companion is an AI-powered study assistant web application designed to help college and university students study more effectively. The application runs entirely on the user's local machine — requiring no internet connection and ensuring complete data privacy. It combines Optical Character Recognition (OCR), Speech-to-Text (STT), and a Large Language Model (LLM) to provide a seamless study workflow: students can scan their textbooks and handwritten notes, ask questions using voice or text in English, Hindi, or Hinglish, and receive AI-generated summaries, step-by-step explanations, and practice questions.

2. Problem Statement

Students often struggle with organizing and revising handwritten notes, understanding complex topics without a tutor, and generating practice material before exams. Existing AI tools (such as ChatGPT) require a constant internet connection, raise privacy concerns with uploaded study material, and are often blocked on campus networks. There is a need for a fully offline, privacy-preserving, AI-powered study tool that works on modern laptop hardware without requiring expensive cloud APIs.

3. Objectives

  • Enable students to extract text from photos of textbooks and handwritten notes using OCR (English & Hindi).
  • Allow voice-based question input via speech-to-text in English, Hindi, and Hinglish.
  • Generate AI-powered summaries, detailed explanations, and fill-in-the-blank practice questions from extracted or typed notes.
  • Run 100% locally on consumer-grade laptops (optimized for Snapdragon X Elite ARM64 processors) with zero cloud dependency.

5. Key Features

  1. Smart OCR: Captures notes via camera or file upload. Preprocessing pipeline (grayscale conversion, contrast enhancement, intelligent resizing) ensures high accuracy even on highlighted or low-resolution images.
  2. Voice Input: 4-second voice recording with automatic transcription using Whisper (base model, int8 quantization for fast CPU inference).
  3. AI Study Modes:
    • Summary — Concise bulleted summaries of study notes.
    • Explain — Step-by-step explanations matching the student's language style.
    • Practice — Auto-generated fill-in-the-blank questions with answer keys.
  4. Fully Offline: All AI models run locally. No data leaves the device.
  5. Responsive UI: Dark-themed, mobile-friendly single-page application.

6. System Architecture

The application follows a client-server architecture running on localhost. The frontend (served as a static HTML file by FastAPI) communicates with three backend API endpoints: /api/ocr for text extraction, /api/stt for speech transcription, and /api/llm which proxies requests to a Llamafile server running the Qwen 2.5 Coder model. The Llamafile server exposes an OpenAI-compatible /v1/chat/completions endpoint on port 8081, while the FastAPI backend runs on port 8000.

7. Hardware Optimization

The application is specifically optimized for the Snapdragon X Elite processor (12-core ARM64):

  • LLM inference uses 10 threads (reserving 2 cores for OS and backend).
  • Whisper STT uses int8 quantization and beam size 3 for fast ARM inference.
  • EasyOCR runs on CPU with intelligent image preprocessing to minimize processing time.
  • GPU offloading is disabled by default (no CUDA), with optional Vulkan support noted for the Adreno GPU.

8. Future Scope

  • Integration with Snapdragon NPU (Neural Processing Unit) for accelerated AI inference.
  • Support for PDF document upload and multi-page OCR.
  • Flashcard generation and spaced repetition scheduling.
  • Multi-user support with local SQLite database for saving study sessions.
  • Offline translation between English and Hindi for bilingual study material.
